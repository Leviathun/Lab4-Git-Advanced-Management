# 🛠️ Git Issues & Rebase Workflow Lab

> A laboratory project dedicated to mastering project management tools within GitHub and practicing advanced Git history management.

---

## 🎯 Learning Objectives
This lab focuses on two core pillars of modern software development:

### 1. Structured Project Management
* **Issue Templates:** Implementation of standardized templates (found in `.github/ISSUE_TEMPLATE`) to streamline bug reporting and feature requests.
* **Collaboration:** Practicing team communication and task tracking via GitHub Issues.

### 2. Advanced Git Techniques
* **Git Rebase:** Practicing the `rebase` workflow to maintain a clean, linear commit history by moving or combining a sequence of commits to a new base commit.
* **Conflict Resolution:** Handling potential conflicts during the rebase process to ensure code integrity.

## 🌿 Branching Strategy
This repository utilizes specific branches for testing advanced workflows:
* **`main`**: The stable production line.
* **`4-testing-the-rebase-and-merge`**: A dedicated branch for practicing rebase-and-merge operations before final integration.

## 📁 Repository Structure
* `.github/ISSUE_TEMPLATE`: Contains the configuration for standardized GitHub Issues.
* `a.txt`, `b.txt`, `c.txt`, `d.txt`: Sample files used to track changes and practice rebase operations.

## 🛠️ Skills Practiced
* **History Rewriting:** Understanding when and how to use `git rebase` safely.
* **Standardization:** Setting up project-wide templates for better team collaboration.
* **Commit Management:** Keeping a logical and readable commit timeline.
